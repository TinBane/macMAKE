# Native 68K application milestone — v0.1.1 closure record

This note records the completed application-baseline work being consolidated
for macMAKE v0.1.1. The independent 68K compiler/provider work is experimental
in the release; the owner-tested makePAD observations below are application-
and artifact-specific development evidence.

## Preserved release and development lines

- PowerPC release base: `release/v0.1.1` at `4ed554f` before consolidation.
- Independent M68K feature line: `feature/native-m68k-toolchain`.
- The isolated consolidated line cherry-picks `b022457`, `0284f62`,
  `26a5632`, `d263743`, `9cf1380`, `0441901`, `c55760a`, and `eabeaed`, then
  fixes SDK runtime-profile acceptance in `8dc918e`.
- The earlier `release/v0.1.1-integrated` line is Retro68-backed historical
  evidence. It is not used as the M68K provider in this candidate.
- The public v0.1.0 archive and installer remain immutable and unchanged.

The independent provider is upstream GNU GCC 12.2.0 and GNU Binutils 2.46.1,
configured for `m68k-unknown-elf` with an M68000 instruction baseline. macMAKE
owns the application startup, Toolbox veneers, bounded CODE-resource model,
resource construction, Finder metadata, and MacBinary packaging. The release
candidate includes no Retro68 compiler, Elf2Mac converter, or Retro68 Rez.
The build-provider isolation fixture sets Retro68 and generic PPC provider
roots to forbidden paths and exercises both a two-translation-unit probe and
HelloWindow through the normal CLI.

## Current independent application profile limits

The release profile covers C89, a single near-model CODE 1 segment, bounded
PC-relative code and global references, file-backed initialized and zeroed
globals, no external linked libraries, and a documented subset of Rez
resources. Multiple code segments, general A5-relative global-data layouts,
external library linking, C++ runtime support, CFM-68K, and complete System 6
compatibility remain outside its current scope. Structural artifact checks
are host-side checks; they do not replace runtime testing on a Macintosh OS.
