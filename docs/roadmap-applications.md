# Future application coverage: makeDRAW

`makeDRAW` is a roadmap idea only. It is not part of v0.1.1 and no source
project has been started.

| Capability area | makePAD v0.1 coverage | Possible makeDRAW coverage |
|---|---|---|
| Window and event loop | Editor window, menus, events | Multiple drawing views and richer interaction |
| Text and document I/O | TextEdit, plain-text Open/Save | Document state and saved graphics data |
| QuickDraw | Minimal UI drawing | Shapes, lines, patterns, clipping and coordinate transforms |
| Resources | Finder bundle, icons, dialogs | Custom palettes, cursor and document resources |
| Floating point | Not a primary application requirement | Geometry and numeric transforms |
| Toolbox breadth | Window, menus, TextEdit, Standard File | QuickDraw and broader Toolbox call coverage |

The purpose would be to exercise additional compiler, runtime, resource,
Toolbox, and application-state behaviors once the owner chooses to begin that
separate project. This table makes no present compatibility or release
commitment.
